# Portfólio de Projetos e Atividades Acadêmicas

Repositório reunindo projetos práticos desenvolvidos durante a graduação em Engenharia de Computação, cursos complementares e maratonas de programação.

## Projetos Incluídos

### 1. Sistema de Gerenciamento de Biblioteca (`/sistema-biblioteca`)
* **Descrição:** Aplicação em terminal para controle de biblioteca com arquitetura de menus hierárquicos (Usuários, Livros, Reservas e Relatórios), com foco na implementação completa do CRUD de usuários e modelagem de dados relacionais em memória.
* **Conceitos aplicados:** Structs aninhadas (`Usuario`/`Endereco`, `Livro`/`Autor`), ponteiros para ponteiros (`**`), alocação e realocação dinâmica de memória (`malloc`/`realloc` com redimensionamento na inserção e remoção) e manipulação segura de strings.
* **Tecnologias:** Linguagem C.

### 2. Zap Mineiro — Sistema de Usuários e Grupos em C (`/zap-mineiro`)
* **Descrição:** Aplicação modularizada em terminal inspirada na estrutura base de um mensageiro, com interface temática regional ("mineirês") e foco em gerenciamento de usuários, criação de grupos e associação de membros.
* **Conceitos aplicados:** Alocação dinâmica de memória (`realloc`/`free`), modularização (`.c`/`.h`), persistência de dados em arquivos de texto, exclusão lógica e ordenação alfabética.
* **Tecnologias:** Linguagem C.

### 3. Projetos Front-End — Formação Alura (`/projetos-frontend-alura`)
* **Descrição:** Conjunto de páginas web desenvolvidas durante cursos práticos de desenvolvimento front-end da Alura, incluindo uma recriação responsiva da interface da Netflix (`/clone-netflix`) e uma landing page comercial para catálogo e venda de produtos de beleza (`/pagina-produtos-beleza`).
* **Conceitos aplicados:** Estruturação semântica em HTML5, estilização e posicionamento com CSS3 (Flexbox/Grid), design responsivo e interatividade básica com JavaScript.
* **Tecnologias:** HTML5, CSS3, JavaScript.
  
### 4. Projeto Hackathon (`/hackathon`)
* **Descrição:** Solução desenvolvida em equipe sob tempo limitado para resolução de problema prático com foco em análise de dados e visualização.
* **Tecnologias:** Python.

### 5. Algoritmos e Estruturas de Dados — AEDS (`/trabalho-aeds`)
* **Descrição:** Implementação de algoritmos e estruturas de dados com foco em eficiência computacional, manipulação de memória e análise de complexidade.
* **Tecnologias:** C / C++.

### 6. Arquitetura e Organização de Computadores — AOC (`/trabalho-aoc`)
* **Descrição:** Projeto de baixo nível envolvendo arquitetura de processadores, lógica digital e execução de instruções.
* **Tecnologias:** Verilog / Assembly.
